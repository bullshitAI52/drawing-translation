# Drawing Translation

Drawing Translation extracts text from DXF drawings, maps translations from Excel, and writes translated labels back to drawing data.

## Workflow

1. Install the Python dependencies from `requirements.txt`.
2. Prepare the source DXF files and the Excel translation mapping.
3. Run the extraction step and review the generated text list.
4. Fill in or import translations using the expected columns.
5. Run the mapping/annotation step and inspect the output drawings.

This repository is an archived source version. Verify dependencies and test with copies of drawings before production use.
